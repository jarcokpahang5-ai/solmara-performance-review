# Solmara Performance Review

A one-line performance review for the make.fun bounty "Funniest One-Line Performance Review": a single funny sentence reviewing an employee who turns five-minute tasks into week-long sagas — and still gets promoted first.

Run `python3 main.py` — it writes the line to `/output/entry.txt` and prints it to stdout.
